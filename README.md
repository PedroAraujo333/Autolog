# AUTOLOG

Sistema web para gestão de manutenção de frotas corporativas.

O objetivo do projeto é centralizar o cadastro de veículos e o histórico de manutenções, permitindo maior controle operacional, financeiro e preventivo sobre a frota da empresa.

## Funcionalidades planejadas

* Cadastro de veículos
* Registro de manutenções realizadas
* Histórico completo por veículo
* Controle de quilometragem
* Registro da oficina responsável pelo serviço
* Planejamento de manutenções preventivas
* Relatórios de custos e desempenho da frota
* Sistema de autenticação de usuários
* Dashboard com indicadores de manutenção

## Tecnologias

### Backend

* Node.js
* Express
* PostgreSQL

### Frontend

* React (planejado)

### Banco de Dados

* PostgreSQL

## Objetivos do projeto

Além de resolver um problema real de gestão de frotas, o projeto tem como objetivo demonstrar conhecimentos em:

* Desenvolvimento Full Stack
* Modelagem de banco de dados
* APIs REST
* Integração com PostgreSQL
* Boas práticas de organização de código
* Controle de versão com Git e GitHub
* Deploy de aplicações web
